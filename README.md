# Rage Edition Menu — Geode mod

A Geometry Dash 2.2081 main-menu makeover for Geode. It keeps the real menu buttons clickable while adding the Rage Edition background and title.

## Android build

The included GitHub Actions workflow builds an Android64 `.geode` package automatically using the official Geode build action. Open the repository's **Actions** tab, run **Build Rage Edition (Android64)**, then download the `RageEdition-Android64` artifact.

For local development, install the Geode SDK and CLI and run `geode build` in this folder.
